# 🎯 ปาเป้าพิชิตเชื้อ 3D

เกมปาลูกดอก 3 มิติ ฝึกความรู้การป้องกันและควบคุมการติดเชื้อ (IC)
หน่วยป้องกันและควบคุมการติดเชื้อ โรงพยาบาลบุรีรัมย์

**เล่นได้ที่:** https://mickkiezz2130-lab.github.io/mickkiezz-github.io/

## สิ่งที่มีในเกม
- **6 ฉาก × 3 ระดับ = 18 ด่าน** (พื้นฐาน → ชำนาญ → เชี่ยวชาญ) ผ่านด่านได้ ★ อย่างน้อย 1 ดวงเพื่อปลดล็อกด่านถัดไป

| ฉาก | เนื้อหา |
|---|---|
| 🏥 หอผู้ป่วยใน | ปาลูกโป่งเชื้อดื้อยา ระวังลูกโป่ง "มือสะอาด" |
| 🧑‍⚕️ ห้องแยกโรคความดันลบ | ลำดับสวม–ถอด PPE |
| 🗑️ จุดพักขยะ | แยกขยะ ติดเชื้อ / ทั่วไป / รีไซเคิล / อันตราย |
| 🫀 ห้อง ICU | 5 Moments ของการล้างมือ |
| 🧼 จุดล้างมือ | ล้างมือ 7 ขั้นตอน |
| 🚑 ห้องฉุกเฉิน | Standard / Contact / Droplet / Airborne Precautions |

- มือ 3 มิติจับลูกดอก ง้าง–ปา–สะบัดข้อมือ · มือส่ายเมื่อเล็งนาน
- ระดับความยาก ง่าย / ปกติ / ยาก (ยากได้เหรียญ ×1.6)
- **โหมดการเล่น:** 👤 คนเดียว · 🤖 แข่งกับบอท 1–3 ตัว · 👥 สร้างห้องเชิญเพื่อน (รหัส/ลิงก์/LINE) · 🎲 สุ่มจับคู่ · ดูจำนวนคนออนไลน์ + สุ่มชวน
- ลงทะเบียน (ชื่อ + หน่วยงาน + PIN) · เหรียญ · โบนัสรายวัน · ได้ 3 ดาวรับไอเทมฟรี
- ร้านค้า: ไอเทมช่วยเล่น (💡 เฉลย, 🛡️ กันพลาด, 🎯 มือนิ่ง, 🐢 ชะลอเป้า, ⏱️ เวลาพิเศษ, ✨ คะแนน ×2) · สกินลูกดอก · เอฟเฟกต์ปาโดน (ประกาย ฟองสบู่ กระดาษสี หัวใจ พลุ) · หางลูกดอก
- สถิติของฉัน · อันดับผู้เล่น · อันดับหน่วยงาน

## เปิดระบบออนไลน์ (ลงทะเบียนข้ามเครื่อง · อันดับรวม · เล่นกับเพื่อน)
1. สร้าง Google Sheet ใหม่ → **ส่วนขยาย → Apps Script** → วางโค้ดจาก `apps-script/Code.gs` → บันทึก
2. เลือกฟังก์ชัน `setup` → **เรียกใช้** → อนุญาตสิทธิ์
3. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป** · เรียกใช้ในฐานะ: *ฉัน* · ผู้มีสิทธิ์เข้าถึง: *ทุกคน* → คัดลอก URL `/exec`
4. ใส่ URL ใน `ic-darts/index.html` ที่บรรทัด `API_URL: ''` (ทุกเครื่องใช้ได้ทันที) หรือในเกม 📊 สถิติ → ⚙️ ตั้งค่า (เฉพาะเครื่องนั้น)

ข้อมูลอยู่ใน Google Sheet: `Players` (ผู้เล่น/สถิติ), `Plays` (ทุกครั้งที่เล่น), `สรุป` (แยกตามด่าน/หน่วยงาน)
ห้องแข่งและรายชื่อคนออนไลน์เก็บชั่วคราวใน CacheService · เหมาะกับการแข่งกลุ่มเล็ก ห้องละไม่เกิน 8 คน

## แก้ไขโจทย์
แก้ในไฟล์ `ic-darts/index.html` ที่ตัวแปร `GERMS`, `PPE_PHASES`, `HW_PHASES`, `WASTE_Q`, `MOMENT_Q`, `PREC_Q` และรายชื่อหน่วยงานที่ `CONFIG.UNITS`
